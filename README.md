# Mail-Vault

A console-based employee email management system built with Java OOP.


Project Overview:

Mail Vault is a Java application designed to create and manage corporate email accounts for employees. It demonstrates object-oriented programming principles such as encapsulation, abstraction, and method overriding. Users can generate secure passwords, set alternate emails, and manage mailbox capacities via a simple menu-driven interface.


Features:

* Create employee email accounts with first name, last name, and department.
* Automatically generate secure random passwords.
* Set and update mailbox capacity.
* Set and update alternate email addresses.
* Display full employee email information in a readable format.
* Menu-driven interface for easy management of account settings.


Technologies Used:

* Java SE
* Object-Oriented Programming (OOP) concepts
* Scanner for user input
